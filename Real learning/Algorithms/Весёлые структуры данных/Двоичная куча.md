#data_structures
Другие названия - куча, пирамида(heap)
**Примечание:** я буду показывать все примеры на минимальной куче - т. е. в её корне будет лежать минимум. Для максимума несложно провести аналогию
## 🔶Идея
### 🔸Что бы мы хотели?
Мы нуждаемся в структуре данных, которая смогла бы быстро найти минимум(или максимум, или элемент с каким-то другим свойством) в каком-нибудь изменяющемся множестве элементов(**Изменяющееся** - значит, поддерживает операции вставки элемента, извлечения максимума, а так же изменения значения какого-нибудь элемента в массиве).
### 🔸Построим дерево с тремя условиями
1. Перед нами **двоичное дерево** - у каждой вершины не более двух детей
2. **Nearly-completed binary tree** - заполнение дерева происходит последовательно, уровень за уровнем, без "дырок". Другими словами, на каждом уровне дерева, кроме последнего, присутствуют все вершины. Последний уровень может не быть заполнен до конца, но он обязательно заполняется слева направо.
3. Значение в каждой вершине **не меньше** значения её родителя.
Так как наше дерево nearly-completed, то его высота всегда равна $\sim \log n$.

### 🔸А зочем?
А теперь подумаем, где находится минимум?
**Ответ:** ему негде быть, кроме как в корне всего дерева, так как все остальные элементы больше либо равны ему. Значит, получить доступ мы можем к нему за $O(1)$

Как вытащить минимум? А давайте "свапнем" его с последним элементом кучи, и без проблем удалим. Теперь проблема может быть только в "корне" кучи - он может не удовлетворять третьему условию минимальной кучи. Что же делать?
**Ответ:** будем его потихонечку "просеивать" вниз, постепенно восстанавливая свойства кучи на каждом слое. На каждом слое нам понадобится $O(1)$ операций, чтобы восстановить порядок - если наша вершина нарушает порядок, то свапаем её с наименьшим из потомков, и спускаемся на уровень ниже. Так как уровней всего $\sim \log n$, то вытащить минимум из кучи мы сможем за $O(\log n)$

Как вставить новый элемент в кучу? Ну, из второго условия следует, что вставлять мы его будем ровно в конец кучи. Но теперь он может нарушить третье свойство кучи. Как быть?
**Ответ:** После того, как мы вставили элемент в конец кучи, будем "просеивать" его вверх до тех пор, пока свойства кучи не восстановятся. Сложность - $O(\log n)$

Что делать, когда мы хотим изменить уже существующее значение в куче?
**Ответ:** меняем его, а затем применяем либо первое "просеивание вверх", либо второе "просеивание вниз" в зависимости от того, уменьшаем мы элемент или увеличиваем
### 🔸А как создать кучу?
Хранить нашу кучу мы будем в массиве, где $a[0]$ - корень, а $a[2 * i + 1]$ и $a[2 * i + 2]$ - левый и правый потомки вершины $i$ соответственно
#### 🔹 За $O(n\log n)$
Представим, что наша куча изначально - пустая. Затем будем добавлять в неё элементы последовательно, один за другим. Каждое добавление сопровождается "просеиванием" вверх, которое занимает $O(\log n)$ времени. Так как элементов всего $n$, имеем асимптотику $O(n\log n)$
#### 🔹 За $O(n)$
Представим, что наш исходный массив - куча, но в ней третье условие не соблюдено. Тогда вызываем "просеивание вниз" от каждой вершины, которая имеет хотя бы одного потомка, ведь для вершин без потомков нет смысла вызвать "просеивание вниз" - некуда 0_0. **Но почему же** $O(n)$?

Заметим, что время "просеивания вниз" зависит от высоты, на которой находится рассматриваемая вершина. Получается, что суммарное время работы всех "просеиваний" будет равно $$\sum_{h=0}^{\lfloor \log n \rfloor }{\frac{n}{2^h} \cdot h}=n \cdot \sum_{h=0}^{\lfloor \log n \rfloor}{\frac{h}{2^h}}=n\left( \frac{1}{2}+\frac{2}{4}+\frac{3}{8}+\dots +\frac{\log n}{n}\right) \leq 2n=O(n)$$
## 🔶 Операции
### 🔸Получение минимума - `GetMin()`
```cpp title="GetMin"
int GetMin(int heap[], int size) {
	return heap[0];
}
```
### 🔸Просеивание вниз - `SiftDown()`
```cpp title="SiftDown"
void SiftDown(int * heap, int size, int i) {
	while (2 * i + 1 < size) {
		int left = 2 * i + 1;
		int right = 2 * i + 2;
		int j = left;
		if (right < size && heap[right] < heap[left]) j = right;
		if (heap[i] <= heap[j]) break;
		std::swap(heap[i], heap[j]);
		i = j;
	}
}
```
### 🔸Просеивание вверх - `SiftUp()`
```cpp title="SiftUp"
void SiftUp(int * heap, int size, int i) {
	while (heap[i] < heap[(i-1)/2]) {
		std::swap(heap[i], heap[(i-1)/2]);
		i = (i-1)/2;
	}
}
```
### 🔸Удаление минимума - `ExtractMin()`
```cpp title="ExtractMin"
int ExtractMin(int * heap, int& size) {
	int mn = heap[0];
	std::swap(heap[0], heap[size - 1]);
	--size;
	SiftDown(heap, size, 0);
	return mn;
}
```
### 🔸Создание кучи - `Heapify()`
Воспользуемся методом создания кучи на исходном массиве за $O(n)$
```cpp title="Heapify"
void heapify(int * heap, int size) {
	for (int i = size / 2; i >= 0; --i) {
		SiftDown(heap, size, i);
	}
}
```
### 🔸Изменение текущего ключа - `DecreaseKey()`
Почему-то в случае с минимальной кучей чаще рассматривают только операцию уменьшения какого-то значения, а в случае с максимальной кучей - только операцию увеличения какого-либо значения.
```cpp title="DecreaseKey"
void DecreaseKey(int * heap, int size, int i, int new_value) {
	heap[i] = new_value;
	SiftUp(heap, size, i);
}
```
### 🔸Вставка - `Insert()`
```cpp title="Insert"
void Insert(int * heap, int& size, int value) {
	heap[size++] = value;
	SiftUp(heap, size, size-1);
}
```

## 🔶Полная реализация(ООП, все дела)
```cpp title="Heap"
#include <iostream>

class Heap {
public:
	template <typename Iter>
	Heap(Iter first, Iter last): data(first, last), sz(last - first) {
		for (int i = sz / 2; i >= 0; --i) {
			siftDown(i);
		}
	}
	  
	int getMin() {
		return data.front();
	}
	  
	int extractMin() {
		int mn = data[0];
		std::swap(data[0], data[sz - 1]);
		--sz;
		siftDown(0);
		return mn;
	}
	  
	void decreaseKey(int i, int new_val) {
		data[i] = new_val;
		siftUp(i);
	}
	  
	void insert(int val) {
		data.push_back(val);
		++sz;
		siftUp(sz-1);
	}
	  
	void print() {
		for (int i = 0; i != data.size(); ++i) {
			if (i != 0) std::cout << ' ';
			std::cout << data[i];
		} std::cout << '\n';
	}
private:
	std::vector<int> data;
	size_t sz = 0;
	  
	void siftDown(int i) {
		while (2 * i + 1 < sz) {
			int left = 2 * i + 1;
			int right = 2 * i + 2;
			int j = left;
			if (right < sz && data[right] < data[left]) {
				j = right;
			}
			if (data[i] <= data[j]) break;
			std::swap(data[i], data[j]);
			i = j;
		}
	}
	  
	void siftUp(int i) {
		while (data[i] < data[(i-1)/2]) {
			std::swap(data[i], data[(i-1)/2]);
			i = (i-1)/2;
		}
	}
};
  
int main() {
int a[] = {10, 1, 31, 200, 34, 25, 78, 160, 11, 99};
Heap hp(a, a + 10);
hp.print();
}
```
