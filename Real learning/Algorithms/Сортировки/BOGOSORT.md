#sort
**Time Complexity:** $O(n * n!)$ в среднем
**Space Complexity:** $O(1)$
**Стабильность:** Нестабильная
## 🔶Идея
Давайте перемешивать массив случайным образом до тех пор, пока не получим отсортированный массив💀
**Кстати**, существуют детерминированная и недетерминированная версия. **Детерминированность** - способность запоминать состояние, в котором мы были, и больше к нему не возвращаться. Другими словами, мы не повторяем свои перетасовки, всегда берём разные.
Моя реализация **недетерминирована**
## 🔶Реализация
**Примечание:** `std::mt19937 rnd(std::chrono...` - штука для наиболее правдоподобной генерации случайных чисел, и при её создании мы сможем их генерировать при помощи `rnd()`
```cpp title="BogoSort"
#include <iostream>
#include <random>
#include <chrono>
  
std::mt19937 rnd(std::chrono::steady_clock::now().time_since_epoch().count());
bool checkIfSorted(int * a, int n) {
	for (int i = 1; i < n; ++i) {
		if (a[i] < a[i - 1]) return false;
	}
	return true;
}
  
void shuffle(int * a, int n) {
	for (int i = 0; i != n; ++i) {
		std::swap(a[i], a[rnd() % n]);
	}
}
  
void BogoSort(int * a, int n) {
	while (!checkIfSorted(a, n))
	shuffle(a, n);
}
  
int main() {
	int a[] = {1, 4, 7, -3, 2, 5, 3, 6, 11, 4};
	BogoSort(a, 10);
	for (int i = 0; i != 10; ++i) {
		if (i != 0) std::cout << ' ';
		std::cout << a[i];
	} std::cout << '\n';
	// -3 1 2 3 4 4 5 6 7 11
}
```

## 🔶Оценка сложности
Ну... тут да
В среднем алгорит переберёт всевозможные варианты и придёт к отсортированному - а всевозможные варианты расположения элементов в массиве это $n \cdot(n-1) \cdot (n-1) \ldots \cdot 1=n!$ вариантов. Ещё и на каждом варианте мы проверяем его на отсортированность за $O(n)$. Имеем
**Time complexity:** $O(n \cdot n!)$
Это средняя оценка. Понятно, что в худшем случае алгоритм не остановится - он будет перемешивать массив бесконечно, и не получит отсортированный вариант
В лучшем же случае мы на первой перетасовке получаем отсортированный массив, но будем честны - каков шанс?

Существуют разные реализации, но в моей мы лишнего места вообще не занимаем, так что 
**Space complexity:** $O(1)$
