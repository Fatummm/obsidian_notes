#sort
англ. - "Selection sort"
## 🔶Идея
Проходимся по массиву, и на каждой $k$-ой итерации выбираем минимальный элемент из ещё неотсортированной части. Очевидно, что в отсортированном массиве он будет стоять на k-ой позиции от начала массива.

## 🔶Реализация
```cpp title=SelectionSort

int main() {
	int arr[] = {1, 23, 3, 2, 0, 2, 3, 5, 2, 4, 1, 2, 4, 6};
	int n = 14;
	for (int k = 0; k < n; ++k) {
		for (int i = k + 1; i < n; ++i) {
			if (arr[i] < arr[k]) {
				int tmp = arr[i];
				arr[i] = arr[k];
				arr[k] = tmp;
			}
		}
	}
}
```
## 🔶Оценка сложности
Временная сложность - $\frac{n(n-1)}{2}=O(n^2)$
Пространственная сложность - $O(1)$
