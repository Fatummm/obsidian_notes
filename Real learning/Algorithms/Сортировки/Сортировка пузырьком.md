#sort
англ. - "Bubble sort"
## 🔶Идея
Наибольший элемент, как пузырик, "всплывает" в конец массива, т. е. мы попарно сравниваем соседние элементы, и если левый элемент больше правого, то меняем их местами(за $O(1)$). 
## 🔶Реализация
```cpp title=BubbleSort
int main() {
	int arr[] = {1, 23, 3, 2, 0, 2, 3, 5, 2, 4, 1, 2, 4, 6};
	int n = 14;
	for (int i = 0; i < n; ++i) {
		for (int j = 1; j < n; ++j) {
			if (arr[j-1] > arr[j]) {
				int tmp = arr[j-1];
				arr[j-1] = arr[j];
				arr[j] = tmp;
			}
		}
	}
}
```
## 🔶Оценка сложности
Общая временная сложность - $O(n^2)$
Пространственная сложность - $O(1)$

**Но на практике можно ускорить алгоритм**
### 🔸1. Тривиальная реализация
Цикл на $n$ итераций внутри цикла на $(n-1)$ итераций - итого $n(n-1)=O(n^2)$
### 🔸2. Чут-чуть изменить границы циклов
Заметим, что для внешнего цикла нет смысла запускать последнюю итерацию, а для внутреннего - идти прям до конца(т. к. после первого прохода на последнем индексе будет наибольший элемент, и двигать его мы уже не будем, после второго прохода - аналогично с предпоследним индексом и т.д.)
```cpp title=BubbleSort
int main() {
	int arr[] = {1, 23, 3, 2, 0, 2, 3, 5, 2, 4, 1, 2, 4, 6};
	int n = 14;
	for (int i = 0; i < n-1; ++i) {
		for (int j = 1; j < n-i; ++j) {
			if (arr[j-1] > arr[j]) {
				int tmp = arr[j-1];
				arr[j-1] = arr[j];
				arr[j] = tmp;
			}
		}
	}
}
```
На практике такой алгоритм уже будет совершать $\frac{n(n-1)}{2}$ элементарных операций.
