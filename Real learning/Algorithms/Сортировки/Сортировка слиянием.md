#sort
англ. - "Merge sort"
**Time Complexity:** $\Theta(n\log n)$
**Space Complexity:** $O(n)$, возможны улучшения до $O(1)$
**Стабильность:** Стабильная
## 🔶Идея
Будем решать задачу **рекурсивно**: разобъём массив длины $n$ на два длиной $\frac{n}{2}$, и будем с каждой половиной будем проделывать такие же трюки, пока не дойдём до тривиального случая -  массивов длиной **1** или **2**.

Отсортировать массив длиной 1 или 2 не составляет особого труда😃

Затем будем объединять, "сливать" полученные массивы в один, с учётом отсортированности.

## 🔶Реализация
```cpp title=MergeSort
#include <iostream>
#include <vector>
template <typename T>
void merge_arrays(typename std::vector<T>::iterator start1,
typename std::vector<T>::iterator end1, typename std::vector<T>::iterator start2, typename
std::vector<T>::iterator end2, typename std::vector<T>::iterator out) {
	std::vector<T> tmp;
	while (start1 != end1 && start2 != end2) {
		if (*start1 > *start2) {
			tmp.push_back(*start2);
			++start2;
		}
		else {
			tmp.push_back(*start1);
			++start1;
		}
	}
	while (start1 != end1) {
		tmp.push_back(*start1);
		++start1;
	}
	  
	while (start2 != end2) {
		tmp.push_back(*start2);
		++start2;
	}
	  
	for (typename std::vector<T>::iterator it = tmp.begin(); it != tmp.end(); ++it) {
		*out = *it;
		++out;
	}
}
   
template <typename T>
void merge_sort(typename std::vector<T>::iterator start, typename std::vector<T>::iterator end) {
	if (end - start >= 2) {
		int mid = (end - start) / 2;
		merge_sort<T>(start, start + mid);
		merge_sort<T>(start + mid, end);
		merge_arrays<T>(start, start + mid, start + mid, end, start);
	}
}
  
int main() {
	std::vector<int> v = {1, 0, 4, 2, 31, 2, 4, 7, 9, -3};
	merge_sort<int>(v.begin(), v.end());
	for (int i = 0; i != v.size(); ++i) {
		std::cout << v[i] << ' ';
	}
}
```
## 🔶Оценка сложности
Временная сложность $T(n) = 2T\left( \frac{n}{2} \right)+\Theta(n)$, где:
$T\left( \frac{n}{2} \right)$ - решение задачи сортировки для половинок массива(т. к. их две, умножаем на два)
$\Theta(n)$ - время слияния двух массивов.
**По мастер-теореме:** $c = 1, a=2, b=2 \Rightarrow c=\log_{b}{a} \Rightarrow T(n)=\Theta(n\log n)$
**Time complexity** - $\Theta(n\log n)$

Пространственная сложность - $O(n)$, т. к. мы создаём промежуточные массивы, в которые записываем "слитые в один" массивы.

## 🔶Вывод
Сортировка слиянием - прекрасный пример "логарифмической" сортировки, а так же замечательный экземпляр, иллюстрирующий метод [[Разделяй и влавствуй]](**Divide and Conquer**). К сожалению, на практике чаще используется модифицированная быстрая сортировка или Timsort(которая вроде использует сортировку слиянием), так как константа перед $n\log n$ слишком велика для реальных проектов(порядка 7).
