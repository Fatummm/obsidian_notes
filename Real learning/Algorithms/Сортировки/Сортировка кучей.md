#sort
Другое название - пирамидальная сортировка
англ. - "Heap sort"
**Time Complexity:** $O(n\log n)$
**Space Complexity:** $O(n)$
**Стабильность:** Нестабильная
## 🔶Идея
А давайте использовать такую смешную конструкцию, как [[Двоичная куча]]. Построить её мы сможем на исходном массиве, а потом вытаскивать минимум и пихать его в ответ $n$ раз.

## 🔶Реализация
### 🔸Использование встроенной кучи из STL
```cpp title="HeapSort"
#include <iostream>
#include <algorithm>
#include <queue>
  
void heapSort(int * a, int n) {
	std::priority_queue<int, std::vector<int>, std::greater<int>> q;
	for (int i = 0; i != n; ++i) q.push(a[i]);
	for (int i = 0; i != n; ++i) {
	a[i] = q.top(); q.pop();
	}
}
  
int main() {
	int a[] = {1, 4, 7, -3, 2, 5, 3, 6, 11, 4};
	heapSort(a, 10);
	for (int i = 0; i != 10; ++i) {
		if (i != 0) std::cout << ' ';
		std::cout << a[i];
	} std::cout << '\n';
}
```

## 🔶Оценка сложности
Строим кучу за $O(n\log n)$, и вытаскиваем из неё минимум ровно $n$ раз, итого 
**Space Complexity:** $O(n\log n)$
По памяти мы кушаем только кусочек для самой кучи - массив на $n$ элементов, поэтому
**Time Complexity:** $O(n)$
