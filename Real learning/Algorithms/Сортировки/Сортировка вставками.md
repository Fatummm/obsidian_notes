#sort
англ. - "Insertion sort"
**Time Complexity:** квадратичная сортировка($O(n^2)$), **но существует лучший случай**
**Space Complexity:** $O(1)$
**Стабильность:** Стабильная
## 🔶Идея
Пусть в массиве отсортирован префикс длины $k$. Как нам в него вставить $k+1$-ый элемент? Двигаем его влево, пока этот элемент меньше своего левого соседа.

## 🔶Реализация
```cpp title=InsertionSort
#include <iostream>

int main() {
	int arr[] = {1, 23, 3, 2, 0, 2, 3, 5, 2, 4, 1, 2, 4, 6};
	int n = 14;
	for (int i = 1; i < n; ++i) {
		for (int j = i; j > 0 && arr[j] < arr[j-1]; --j) {
			int tmp = arr[j];
			arr[j] = arr[j-1];
			arr[j-1] = tmp;
		}
	}
}
```
## 🔶Оценка сложности
**Временная сложность**(цикл в цикле) - в среднем $O(n^2)$
Но появляется лучший случай, когда массив изначально отсортирован - тогда сложность будет составлять $O(n)$
**Пространственная сложность** - $O(1)$

Первая сортировка(если вы их изучаете по порядку: квадратичные -> более быстрые), в которой существует лучший случай работы алгоритма - $O(n)$, если массив изначально был отсортирован. Поэтому при малых $n$ данная сортировка иногда применяется в смешанных сортировках
