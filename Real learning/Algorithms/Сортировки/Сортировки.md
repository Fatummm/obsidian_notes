## 2.12 Все сложности сортировок
**Примечание:** звёздочкой отмечены сложности, чаще всего упоминаются в литературе, но могут быть улучшены / ухудшены, в зависимости от языка и реализации

|                | Best case         | Average case      | Worst case        | Space complexity |
| -------------- | ----------------- | ----------------- | ----------------- | ---------------- |
| Bubble sort    | $O(n^2)$*         | $O(n^2)$          | $O(n^2)$          | $O(1)$           |
| Selection Sort | $O(n^2)$          | $O(n^2)$          | $O(n^2)$          | $O(1)$           |
| Insertion Sort | $O(n)$            | $O(n^2)$          | $O(n^2)$          | $O(1)$           |
| Merge Sort     | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(n)$*          |
| Quick Sort     | $O(n\log n)$      | $O(n\log n)$      | $O(n^2)$          | $O(\log n)$      |
| Heap Sort      | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $O(n)$           |
| CountSort      | $O(n + k)$        | $O(n + k)$        | $O(n + k)$        | $O(k)$           |
| Radix Sort     | $O(d(n+k))$*      | $O(d(n+k))$*      | $O(d(n+k))$*      | $O(n+k)$*        |
| BOGOSORT       | $O(n)$            | $O(n\cdot n!)$    | $\infty$*         | $O(1)$           |
**Важно:** сложности, отмеченные звёздочкой, в других источниках могут иметь другие величины - зависит от реализации и учёта некоторых значений.
