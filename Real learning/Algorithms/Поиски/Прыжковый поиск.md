#search
англ. - "Jump search"
условия: **отсортированный набор данных**
**Time Complexity:** $O\left( \frac{n}{m} + m \right)$, где $m$ - длина прыжка
**Space Complexity:** $O(1)$
## 🔶Идея
Проходиться по **каждому элементу отсортированного массива** слишком долго, давайте попробуем пропускать определённое количество элементов после каждого неудачного сравнения( = рассматриваемый элемент меньше искомого).
Если доходим до конца массива и последний элемент меньше искомого, значит, искомого элемента в массиве вообще нет

Если мы встречаем первый элемент, больший заданного, делаем прыжок обратно и в получившемся окошке, длина которого равна длине прыжка, линейным поиском ищем нам нужный элемент.

## 🔶Реализация
```cpp title="jumpSearch"
#include <iostream>
#include <vector>
#include <cmath>
  
int jumpSearch(std::vector<int>& v, int val) {
	int m = sqrt(v.size()); // наиболее оптимальный выбор длины прыжка
	int i;
	for (i = 0; i < v.size(); i += m) {
	if (v[i] == val) return i;
	if (v[i] > val) break;
	}
	i -= m;
	for (; i < std::min(static_cast<int>(v.size()), i + m); ++i) {
	if (v[i] == val) return i;
	}
	return v.size();
}
  
int main() {
	std::vector<int> v = {0, 2, 3, 5, 10, 11, 12, 17, 20};
	int ind = jumpSearch(v, 17); // 7
}
```

## 🔶Оценка сложности
### 🔸Time Complexity
Пусть длина прыжка - $m$. Сколько прыжков мы сделаем? Максимум мы "пропрыгаем весь массив", значит - $O\left( \frac{n}{m} \right)$. После всех прыжков мы будем линейно идти по окошку длины $m$ в худшем случае. Значит, это ещё $O(m)$. Получаем
**Time Complexity:** $O\left( \frac{n}{m}  + m\right)$
### 🔸 Best time complexity
Как оптимально выбрать $m$?
Вот дали нам массив длины $n$. Мы знаем, что вне зависимости от выбора $m$ сложность составит $O\left( \frac{n}{m} + m \right)$. Как эту штуку свести к минимуму?
Рассмотрим функцию $f(m) = \frac{n}{m} + m$, где $n$ - какая-то константа(данный нам размер массива).
Как найти у неё точку минимума? $\implies$ Найти производную, приравнять к нулю
$$f'(m)=\left(\frac{n}{m}\right)' + m'=-\frac{n}{m^2} + 1$$
$$-\frac{n}{m^2}+1 = 0 \implies m = \sqrt{n}$$
Нужно бы ещё проверить, что это точка минимума, а не максимума, с этим сами справитесь
При $m=\sqrt{ n }$ получаем **сложность** 
$$O\left( \frac{n}{\sqrt{ n }}+\sqrt{ n } \right)=O(2\sqrt{ n })=O(\sqrt{ n })$$

### 🔸 Space complexity
По памяти мы ничего лишнего не кушаем, поэтому
**Space Complexity:** $O(1)$

## 🔶Выводы
Ну прикольный поиск, который находит элемент за $O(\sqrt{n})$ - быстро, но не настолько, чтобы быть лучше бинарного
