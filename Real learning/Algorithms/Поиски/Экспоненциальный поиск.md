#search 
англ. - "Exponential search, galloping search, doubling search, Struzik search"
условия: **отсортированный набор данных**, **обычно используется на бесконечном наборе входных данных**
**Time Complexity:** $O(\log i)$, где $i$ - индекс искомого элемента(или места, где он должен был быть)
**Space Complexity:** $O(1)$
## 🔶Идея
Давайте модифицируем [[Прыжковый поиск]]: после каждого прыжка увеличиваем длину прыжка. Затем, после того, как найдём элемент, больший искомого, отскакиваем назад и бинарным поиском ищем наш элемент

## 🔶Реализация
(использую встроенный бинарный поиск)
```cpp title="Exponential Search"
#include <iostream>
#include <vector>
#include <algorithm>
  
int exponentialSearch(std::vector<int>& v, int val) {
	int pw = 1;
	int ind = 0;
	while (ind + pw < v.size() && v[ind] < val) {
		ind += pw;
		pw *= 2;
	}
	auto it = std::lower_bound(v.begin() + ind - pw,
	v.begin() + std::min(ind, static_cast<int>(v.size())), val);
	  
	if (it == v.end() || *it != val) return v.size();
	return it - v.begin();
}
  
int main() {
	std::vector<int> v = {0, 2, 3, 5, 10, 11, 12, 17, 20};
	int ind = exponentialSearch(v, 17); // 7
}
```

## 🔶Оценка сложности
### 🔸Time Complexity
Пусть наш элемент сидит на позиции $i$. Как нам до него добраться?
**Первым шагом будет наш галоп** сколько раз мы будем увеличивать прыжок? В среднем за $O(\log_{2}{i})$ управимся

Теперь остался бинарный поиск. А на каком отрезке мы его запустим? На отрезке длины $2^{\log_{2}{i}}-2^{\log{i}-1}=2^{\log{i}-1}$. Значит, потратим ещё $O(\log_{2}{2^{\log{i}-1}})=O(\log{i}-1)=O(\log i)$
Получаем 
**Time Complexity:** $O(\log i) + O(\log i) = O(2 \log i) = O(\log i)$
