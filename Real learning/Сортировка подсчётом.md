#sort 
англ. - "Count sort"
**Time Complexity:** $O(n + k)$, где $k$ - диапазон значений
**Space Complexity:** $O(k)$
**Стабильность:** Стабильная(если захотите)
## 🔶Идея
Если мы знаем, что в данном нам массиве различных значений мало относительно их количества(например, $10^6$ чисел из отрезка $[1, 100]$), то можем воспользоваться следующей идеей: а давайте считать, сколько единичек мы имеем в массиве, сколько двоек получили, сколько троек получили, $\dots$, сколько получили чисел, равных $100$. Это можно сделать, представив наши числа как индексы в массиве $b[1, 2, \dots, 100]$. Тогда в элементе $b[x]$ будет лежать число, соответствующее количеству вхождений числа $x$ в исходный массив. Имея такой массив, мы сможем восстановить исходный, да к тому же отсортированный - проходимся по массиву $b$ и, встретив ненулевое число, выводим индекс столько раз, какое число вы встретили

### 🔸Example
**Входные данные**
$$
\begin{array}{\left}
n=10 \\
k=[1, 10](\text{диапазон значений}) \\
a=[1, 5,  2, 1, 6, 8, 2, 4, 1, 6]
\end{array}
$$
Тогда массив $b$ будет выглядеть следующим образом:
$$\begin{array}{}
b_{1}=3 && b_{6}=2 \\
b_{2}=2 && b_{7}=0\\
b_{3}=0 && b_{8}=1\\
b_{4}=1 && b_{9}=0\\
b_{5}=1 && b_{10}=0
\end{array}$$
Осталось пройтись по этому массиву и вывести числа в соответствующем порядке.
## 🔶Реализация
```cpp title=countSort
#include <iostream>
#include <vector>
  
template <typename Iter>
void countSort(Iter begin, Iter end, int k) {
	std::vector<int> b(k+1, 0);
	for (Iter it = begin; it != end; ++it) b[*it]++;
	Iter ptr = begin;
	for (int i = 0; i != k + 1 && ptr != end; ++i) {
		while (b[i]--) {
			*ptr = i;
			++ptr;
		}
	}
}
  
int main() {
	std::vector<int> v = {1, 0, 4, 2, 31, 2, 4, 7, 9, 2};
	countSort(v.begin(), v.end(), 100);
	for (int i = 0; i != v.size(); ++i) {
		std::cout << v[i] << ' ';
	}
	std::cout << '\n';
}
```
